========================================
  卡坦島 Catan — USB 便攜版
  Windows / Mac 都用得
========================================

【Windows 最快玩法】
1. 插入 USB
2. 打開資料夾 Catan_Katan_Island
3. 雙擊 Play_Catan.bat
   （或 開始遊戲.bat，或直接雙擊 index.html）

【如果畫面空白】
雙擊 Play_Catan_Server.bat
瀏覽器會開 http://localhost:8765/
玩完喺黑色視窗按 Ctrl+C

【Mac】
雙擊 index.html 即可

【遊戲簡介】
- 目標：10 分勝利
- 1–4 人類玩家（同一部電腦輪流 = 熱座）
- 可加 AI
- 支援玩家交易 + 銀行交易
- 多種地圖模式

【檔案】
index.html          ... 遊戲本體（雙擊可玩）
Play_Catan.bat      ... Windows 一鍵開
開始遊戲.bat        ... 同上
Play_Catan_Server.bat ... 備用伺服器模式
README.md           ... 詳細說明（英文標點版面）
README.txt          ... 本檔

【需求】
Windows 10/11 + Edge/Chrome 等瀏覽器
唔使安裝、唔使上網、唔使帳號

【FAQ】
Q: bat 被防毒攔截？
A: 只係開本機網頁；可直接開 index.html

Q: 可複製去第部機？
A: 可以，成個資料夾 copy 走就得

玩得開心！
