# 卡坦島 · Catan vs AI

瀏覽器版《卡坦島》（Settlers of Catan）：單人 vs AI，或多人熱座，**唔使安裝**。

## 立即遊玩（GitHub Pages）

**https://takjai18.github.io/catan-web/**

（若連結暫時 404，等 1–2 分鐘讓 Pages 完成部署，或到 repo 的 **Settings → Pages** 確認已啟用。）

## 本機開啟

```bash
cd catan-web
python3 -m http.server 8765
```

然後打開 http://localhost:8765

亦可直接用瀏覽器開 `index.html`（部分瀏覽器對 `file://` 模組有限制，建議用本機伺服器）。

USB 便攜版見 `portable/` 資料夾（含 Windows `.bat`）。

## 功能

| 項目 | 說明 |
|------|------|
| 玩家 | 1–4 人類（熱座）+ 可選 AI，總共 2–4 人 |
| 地圖 | 經典平衡、無沙漠、新手、聚集、隨機等 |
| 建造 | 路、村莊、城市、發展卡 |
| 交易 | 銀行（港口 3:1 / 2:1）、玩家之間交易 |
| 特殊 | 強盜、最長道路、最大軍隊、隱藏勝利點卡 |
| 勝利 | 10 分 |

## 操作簡述

1. 設置：每人放 2 村莊 + 2 路  
2. 回合：擲骰 → 收資源 → 建造／交易 → 結束回合  
3. 建造：先按側欄按鈕，再點地圖  
4. 擲出 7 或打出騎士：點地塊移動強盜  

## 技術

純前端：HTML + CSS + ES Modules，無需後端。
